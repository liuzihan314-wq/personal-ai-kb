# Goal 施工清单：多用户访问、版本归档与 GitHub 展示

## 目标

在保持当前 V1 本地知识库能力可回归的前提下，规划并推进 V2 多用户访问：通过 Cloudflare Access 提供 HTTPS 与登录入口，腾讯云服务器运行现有 Python／Streamlit 应用，应用按用户隔离知识库与历史记录。同时归档当前稳定版本，完善 GitHub 项目介绍和展示素材，形成可用于黑客松报名的公开说明。

## 当前基线

- 当前稳定提交：`cd00dd2`，主分支工作区此前已验证干净，V1 测试基线为 `98 passed`。
- V1 文档明确是单用户、本地优先，不包含登录、权限和云端部署；因此 V2 开始前必须先完成设计文档对齐，不能直接在现有 V1 约束下添加云端多用户代码。
- 现有技术栈继续复用 Python、Streamlit、文件系统和 `.env`；Cloudflare 负责入口与访问控制，腾讯云负责应用运行和持久化存储。

## 最小垂直切片

先只验证两个测试身份（管理员 A、普通成员 B）：

1. 两个身份能通过 Cloudflare Access 到达同一个应用入口。
2. 应用能稳定取得用户唯一标识和角色，并显示当前登录身份。
3. 每个用户的 `raw`、`notes`、`knowledge`、`index`、问答历史都写入独立目录，例如 `data/users/<user_id>/...`。
4. A 与 B 互相不能读取、检索或下载对方内容；无身份请求被拒绝。
5. V1 单用户本地模式仍可运行，且已有 PDF、卡片、检索、问答和口播回归测试通过。
